# 5v5 FPS

브라우저에서 즐기는 로컬 싱글플레이 3D 1인칭 슈팅 게임 (Three.js + React + Vite)

## 게임 규칙
- **5 vs 5**: 내 캐릭터 + 아군 AI 4 vs 적군 AI 5
- **5라운드 중 3선승**으로 승패 결정
- **라운드마다 랜덤 총 지급** (권총 / 기관단총 / 소총 / 산탄총 / 저격총 / 경기관총)
- **칼은 항상 지급**, 칼을 들었을 때만 이동 속도 증가 (+35%)
- **체력 100** 기준 총기 밸런스
- 라운드는 **한 팀이 전멸하면 종료** (마지막 생존 팀 승리)

## 조작법
| 키 | 동작 |
| --- | --- |
| `W A S D` | 이동 |
| `마우스` | 시점 회전 |
| `좌클릭` | 공격 |
| `1` / `2` | 총 / 칼 전환 |
| `R` | 재장전 |
| `Space` | 점프 |
| `Esc` | 일시정지 |

## 실행
```bash
npm install
npm run dev
```

## 빌드 & 배포
```bash
npm run build       # dist/ 생성
npm run deploy      # GitHub Pages(gh-pages) 배포
```
